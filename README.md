# Alaklouk — Responsive Website Template

Alaklouk is a responsive, multi-section website template built with HTML and CSS. It provides a structured landing page layout with reusable content sections, navigation, cards, pricing layouts, and a contact-style form.

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Header navigation with a mega menu linking to the main sections.
- Landing section with introductory content.
- Articles section with content cards.
- Image gallery.
- Features section with highlighted feature cards.
- Testimonials and team members sections.
- Services and skills sections.
- How It Works section.
- Events section with subscription form layout.
- Pricing plans section.
- Top videos preview section.
- Statistics section.
- Discount request form layout.
- Footer with social links, contact details, and an image gallery.
- CSS transitions, hover effects, and animations.

## Built With

- **HTML5** — page structure and content.
- **CSS3** — layout, responsive styles, transitions, and animations.
- **Font Awesome** — icons.
- **Google Fonts** — typography.
- **Normalize.css** — consistent default browser styling.

## Getting Started

This is a static frontend project. It does not require Node.js, Python, a package manager, or a build process.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/abdulkarimaklouk/template-alaklouk.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` directly in your browser, or use the **Live Server** extension in Visual Studio Code:
   - Right-click `index.html`.
   - Select **Open with Live Server**.

## Notes

- The project is a frontend template; it does not include a backend or JavaScript application logic.
- The subscription and discount request forms are presentation elements only. They are not connected to a server or submission service.
- Text, profile details, pricing information, and other sample content can be replaced to fit your use case.
